# ItemsAdder API

This repository only provides access to the Java API method signatures of ItemsAdder.

> [!IMPORTANT]
> This repository does **NOT** contain the source code of ItemsAdder.  
> To use and test this API you still need a valid copy of :contentReference[oaicite:0]{index=0}.

</h3>

---

> [!WARNING]
> When using the API you should listen to the `ItemsAdderLoadDataEvent`
> to make sure items are fully loaded before accessing them.
>
> ItemsAdder loading is asynchronous.
